# PDF 필기장

PDF를 과목·단원 폴더로 정리하고, 그 위에 필기하는 Windows 데스크톱 앱입니다.
필기는 자동으로 저장되고 언제든 다시 고칠 수 있으며, 인터넷 연결 없이 동작합니다.

## 주요 기능

- **라이브러리:** 폴더 트리로 분류, 최근 수정 문서, 문서 이름 검색, 첫 페이지 미리보기
- **자동 저장:** 원본 PDF는 그대로 두고 필기만 따로 저장해서, 다시 열어도 필기를 지우거나 고칠 수 있음
- **정리:** 이름 바꾸기, 끌어다 놓아 폴더 옮기기, 휴지통으로 삭제
- **내보내기:** 필기를 합친 PDF 파일로 내보내기 (메모장은 맨 뒤에 붙음)
- **메모장:** PDF 옆에 여는 빈 노트. 문서마다 여러 개, 종이는 무지·줄 노트·모눈 중 선택
- **올가미:** 필기를 감싸서 선택하고 옮기기·크기 조절·색 바꾸기·복사·삭제
- **영역 복사와 붙여 넣기:** PDF 일부를 네모로 잡아 복사(`G`)하거나 Windows 스크린샷(`Win+Shift+S`)을 찍어 `Ctrl+V`로 메모장에 붙여 넣기
- **암기 모드:** 형광펜 상태에서 `E`를 한 번 더 누르면 형광펜 친 부분이 가려지고, 가린 곳을 누르면 보임
- **페이지 목록:** 왼쪽에 페이지 미리보기, 눌러서 이동
- **텍스트 꾸미기:** 굵게, 배경색
- **PDF 본문 검색:** PDF 안의 낱말 찾기 (스캔·이미지 PDF는 글자가 없어 검색되지 않음)
- **필기 도구:** 펜, 형광펜, 도형(사각형·원·화살표·별), 텍스트, 지우개
- **필기 옵션:** 색상 5가지, 굵기 3단계, 글자 크기 6–120
- **텍스트 편집:** 글자를 클릭하면 수정, 드래그하면 이동
- **PDF·이미지 가져오기:** JPG·PNG 등 이미지는 한 장이 PDF 한 페이지가 되고, 여러 장은 한 문서로 묶을 수 있음. 가져오기 버튼, 창에 끌어다 놓기, 앱 아이콘에 끌어다 놓기, Windows의 "연결 프로그램"
- **보기:** 확대·축소, 폭에 맞추기, 다크 모드(시스템 설정을 따름)
- **실행 취소:** 실행 취소와 다시 실행 지원
- **한글 지원:** 한글 입력 상태에서도 단축키가 동작하고, 글꼴을 포함하지 않은 한글 PDF도 표시
- **오프라인 동작:** 라이브러리와 글꼴을 앱에 모두 포함

## 설치

1. [최신 릴리스](https://github.com/imgh0204/pdf-notebook/releases/latest)에서 `PDF-Notebook-Setup-2.0.0.exe`를 내려받습니다.
2. 내려받은 파일을 실행해 설치합니다. 설치 대상을 묻는 화면에서는 **현재 사용자만**을 고르세요. 관리자 권한이 필요 없고, 이전 버전을 설치했다면 그 위에 덮어서 업데이트됩니다.

Windows 64비트용입니다. 코드 서명이 없어 SmartScreen 경고가 뜰 수 있는데, 이때는 **추가 정보 → 실행**을 누르면 됩니다.

## 사용 방법

1. 처음 실행하면 필기를 보관할 폴더를 고릅니다. 기본값은 `문서\PDF 필기장`이고, 빈 폴더라면 연습용 샘플 문서가 들어갑니다.
2. **새 폴더**로 과목·단원 폴더를 만들고, **PDF 가져오기**로 PDF를 넣습니다.
3. 문서를 열어 필기합니다. 필기는 자동으로 저장됩니다.
4. 다른 사람에게 보내려면 **PDF로 내보내기**(`Ctrl+E`)를 누릅니다. 파일 이름은 `원본이름_필기.pdf`가 기본값입니다.

### 저장 폴더 구조

라이브러리 폴더 안의 하위 폴더가 그대로 앱의 폴더 트리가 됩니다. 문서 하나는 원본 PDF와 필기 파일로 저장됩니다.

```text
PDF 필기장/
  수학/
    미적분/
      1강 극한.pdf                원본 PDF (수정하지 않음)
      .필기장/                    숨김 폴더
        1강 극한.필기.json         필기, 메모장, 미리보기
        1강 극한.필기-이미지.json   붙여 넣은 이미지 (있을 때만)
```

필기 파일은 각 폴더의 숨김 폴더 `.필기장`에 있어서 탐색기에는 PDF만 보입니다. 탐색기에서 PDF를 직접 넣어도 앱에 나타나지만, 탐색기에서 PDF 이름을 바꾸거나 옮기면 필기가 따라가지 않으니 이름 바꾸기와 옮기기는 앱 안에서 하세요. (예전 버전처럼 PDF 옆에 있던 필기 파일은 앱이 자동으로 `.필기장`으로 옮깁니다.)

## 단축키

| 키 | 동작 |
| --- | --- |
| `Q` / `Space` | 이동 (`Space`는 누르는 동안만) |
| `W` / `E` | 펜 / 형광펜 (`Shift`를 누르면 직선) |
| `E` 한 번 더 | 암기 모드 켜기·끄기 |
| `G` | 페이지 목록 열기·닫기 |
| `R` | 도형 (누를 때마다 사각형 → 원 → 화살표 → 별, `Shift`: 정사각형·정원) |
| `A` | 텍스트 |
| `S` | 지우개 |
| `D` | 올가미 (닿게 감싸면 선택, 끌어서 옮기기, 오른쪽 아래 모서리로 크기 조절) |
| `F` | 영역 복사 (PDF에서 네모로 잡으면 이미지로 복사) |
| `M` | 메모장 열기·닫기 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 선택한 필기 복사 / 잘라내기 / 붙여 넣기 (스크린샷·글자도 붙여 넣기) |
| `Delete` | 선택한 필기 지우기 |
| `1`–`5` | 색상 선택 |
| `[` / `]` | 굵기 또는 글자 크기 조절 |
| `Ctrl+Z` | 실행 취소 |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 다시 실행 |
| `+` / `-` / `0` | 확대 / 축소 / 폭에 맞추기 (`Ctrl`+휠도 가능) |
| `Ctrl+O` | PDF 가져오기 |
| `Ctrl+S` | 바로 저장 (평소에는 자동 저장) |
| `Ctrl+E` | PDF로 내보내기 |
| `Ctrl+F` | PDF 본문에서 찾기 (라이브러리 화면에서는 문서 이름 찾기) |
| `Ctrl+Shift+N` | 새 폴더 (라이브러리 화면) |
| `?` | 단축키 도움말 |

텍스트를 입력할 때는 `Enter`로 완료, `Shift+Enter`로 줄바꿈, `Esc`로 취소합니다.

## 알아둘 점

- **라이브러리 밖의 PDF는 자동 저장되지 않습니다.** "연결 프로그램"으로 연 PDF가 라이브러리 밖에 있으면 **라이브러리에 추가**해야 필기가 저장됩니다.
- **내보낸 PDF의 필기는 고칠 수 없습니다.** 내보낸 파일은 필기가 이미지로 합쳐진 사본이므로, 고칠 때는 앱의 라이브러리에서 고친 뒤 다시 내보내세요.
- **저장 폴더를 바꿔도 파일은 옮겨지지 않습니다.** 옮기려면 탐색기에서 폴더를 통째로 옮긴 뒤 그 폴더를 고르세요.
- **암호가 걸린 PDF는 열 수 없습니다.**
- **한글(HWP)·PowerPoint·Word 파일은 가져올 수 없습니다.** 각 프로그램에서 "PDF로 저장"한 뒤 가져오세요.
- **스캔하거나 이미지로 만든 PDF는 본문 검색이 되지 않습니다.**

## 개발

[Node.js](https://nodejs.org/)가 필요합니다.

```bash
git clone https://github.com/imgh0204/pdf-notebook.git
cd pdf-notebook
npm install
npm start
```

설치 파일을 만들려면 다음 명령을 실행합니다. 결과물은 `dist` 폴더에 생성됩니다.

```bash
npm run dist
```

`npm start`와 `npm run dist`는 먼저 `scripts/vendor.js`를 실행해 라이브러리와 글꼴을 `src/vendor`로 복사합니다. 이 폴더는 자동으로 만들어지므로 Git에 포함하지 않습니다.

### 프로젝트 구조

```text
build/icon.png      앱 아이콘
scripts/vendor.js   라이브러리와 글꼴을 src/vendor로 복사
src/main.js         Electron 메인 프로세스 (창, 라이브러리 파일 관리, 내보내기)
src/preload.js      화면과 메인 프로세스를 잇는 API
src/index.html      라이브러리 화면과 필기 기능 전체
```

### 사용 기술

- [Electron](https://www.electronjs.org/): 데스크톱 앱
- [PDF.js](https://mozilla.github.io/pdf.js/): PDF 표시
- [pdf-lib](https://pdf-lib.js.org/): 필기를 합쳐 PDF 저장
- [electron-builder](https://www.electron.build/): Windows 설치 파일 생성
- IBM Plex Sans KR, IBM Plex Mono: 글꼴
